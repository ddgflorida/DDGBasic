# Sample data

`chinook.sqlite` is the Chinook sample database, a small music store: artists, albums, tracks, customers, employees, invoices and invoice lines. It is used by `examples/invoice_demo.bas`.

Chinook was created by Luis Rocha and is published at <https://github.com/lerocha/chinook-database> under the MIT License. The examples copy it into memory before changing anything, so the file here stays as published.
