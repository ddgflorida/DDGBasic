# Changelog

## 0.1.1

- F5 and Ctrl+F5 run the program (no more "select debugger" prompt). launch.json entries of type `ddgbasic` can name the program.
- Removed the Cmd+F5 key on the Mac, which is the VoiceOver shortcut.

## 0.1.0

- Syntax highlighting generated from the interpreter, hover help from HELP, and a Run command.
